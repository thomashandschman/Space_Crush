# 🚀 Space Crush

Ein Weltraum-Shooter für Kinder — fliege dein Raumschiff, zerstöre Asteroiden mit Laserstrahlen, sammle Lasersterne und besiege am Ende jedes Levels einen Endgegner!

## Spielen

Einfach die Datei **`index.html`** im Browser öffnen (Doppelklick genügt) — keine Installation nötig. Funktioniert am Computer, Tablet und Handy.

## Steuerung

| Gerät | Steuerung |
|---|---|
| **Computer** | Pfeiltasten / WASD = fliegen · Leertaste = Laser (gedrückt halten für Dauerfeuer) · **X** = Mega-Laser · **M** = Ton an/aus |
| **Tablet / Handy** | Finger über den Bildschirm bewegen = fliegen (der Laser feuert automatisch) · Auf den ⭐-Button tippen = Mega-Laser |

## So funktioniert's

- **Asteroiden abschießen**: Große Asteroiden zerbrechen in kleinere — kleine geben mehr Punkte!
- **Lasersterne sammeln** ⭐: 5 Sterne füllen die Power-Anzeige → **Mega-Laser** bereit (riesiger Superstrahl, der alles wegfegt)
- **Endgegner**: Am Ende jedes Levels wartet ein Boss mit Lebensbalken — Level 1: Mega-Brocken · Level 2: Alien-UFO · Level 3: Mutterschiff
- **3 Schwierigkeitsstufen**: Leicht (5 Leben, langsam), Mittel, Schwer
- **4 Raumschiffe** zur Auswahl — darunter das Original nach der Vorlage des Chefdesigners ✏️

## Technik

Alles in einer einzigen HTML-Datei: HTML5 Canvas für die Grafik (Vektor-Zeichnungen, keine Bilddateien) und Web Audio API für die Sound-Effekte (alle Töne werden live erzeugt — inklusive **Boooooom** 💥).
